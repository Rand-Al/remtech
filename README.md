# MVP сайта сервиса ремонта техники

Статический сайт для локального сервиса ремонта техники в Броварах.

## Что уже есть

- Главная страница.
- 8 SEO-страниц услуг.
- Форма заявки с обязательным согласием на платную диагностику.
- Мини-чат квалификации заявки без советов по ремонту.
- `sitemap.xml`, `robots.txt`, canonical, Open Graph, JSON-LD.
- Cloudflare Pages Function для отправки заявок в Telegram.

## Что нужно заменить перед запуском

- `+38 000 000 00 00` на реальный телефон.
- `example.com` в `sitemap.xml`, `robots.txt` и canonical-ссылках на реальный домен.
- Название сервиса, график, зоны выезда.
- Реальные фото работ вместо `assets/repair-hero.png`, когда они появятся.
- Реальные условия гарантии, если гарантия предоставляется.
- ID Google Analytics после создания счетчика.

## Telegram-заявки

Для Cloudflare Pages добавьте переменные окружения:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Форма отправляет заявки на `/api/lead`. Если переменные еще не настроены, заявка сохраняется в браузере как черновик.

## Запуск локально

Можно открыть `index.html` напрямую в браузере. Для проверки функции Telegram используйте Cloudflare Pages локально или после деплоя.
